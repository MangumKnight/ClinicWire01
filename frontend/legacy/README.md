# Legacy Frontend

This is a temporary static HTML interface for ClinicWire.

## Status

**⚠️ TEMPORARY**: This interface will be replaced with a modern React/Next.js dashboard in the next release.

## Usage

```bash
# From the frontend/legacy directory
python -m http.server 8002

# Open in browser
http://localhost:8002/index.html
```

## Features

- POC task creation form
- Real-time task status monitoring
- Basic call management
- SMS notification tracking

## Planned Replacement

The new dashboard will feature:
- Modern React/Next.js architecture
- Real-time updates via WebSocket
- Advanced analytics and reporting
- Improved UX/UI design
- Role-based access control
